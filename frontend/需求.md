
定位：企业级ai赋能平台

目标：使用ai结合企业现有流程进行流程优化

技术：vue fastapi redis mysql docker git llama.cpp rag skill mcp

覆盖场景及功能：
1.计划制定，上司为下属分配任务，ai通过任务制定计划并共同设计交付时间节点。
2.流程设计，员工提交一个事物请求（如邀请客户参观工厂，员工在ai帮助下完成信息填写，然后转交给负责人，负责人能够通过ai的分析和建议要求补充信息或者通过。可以有多个负责人）
3.报销流程，上传发票ai通过文字提取与识别完成自动化数字归档并提交财务。
4.数据建库，公司的规章制度，合同，sop流程等pdf类似数据通过rag保存并能更新和修改，为员工提供便捷服务。
5.实时数据分析，通过销售额，成本，利润等数据进行ai分析，发现问题与优势。
6.公告与自动推送，公司发布公告，ai通过分析公告自动提示涉及部门员工
7.对话总结与计划制定，ai分析对话内小组对话分析出分歧，目标与要求，并能自动规划计划供人员修改与执行。
8.直接对话寻求服务：员工直接向ai寻求帮助，可以调用skill和mcp
